### 🤖 Harry Potter Knowledge-Grounded AI Chatbot

An LLM-powered chatbot designed to provide reliable question answering using a structured knowledge base.

The system implements controlled response generation where answers are restricted to information available in the provided dataset, reducing hallucination and improving response accuracy. The chatbot includes conversational handling for user interactions while maintaining knowledge boundaries.

### 🚗 Real-Time Lane Drift Detection using YOLOPv2 & CARLA

A computer vision pipeline developed for detecting vehicle lane deviation and monitoring driving behavior in real time.

The system uses YOLOPv2-based perception, OpenCV image processing, and CARLA simulation to analyze road scenes, identify lane boundaries, and calculate vehicle drift from the lane center. The project demonstrates the application of deep learning for intelligent transportation systems.

**Technologies:**
`Python` · `PyTorch` · `YOLOPv2` · `OpenCV` · `CARLA Simulation`
